# Phase 2E security and concurrency audit

Baseline Core: `257642139acd325e3771b0e11d0d0b5384ad672b` (see
[Phase 2D reconciliation](PHASE2D_RECONCILIATION.md) for pinned external repository
revisions and frozen Phase 2D binary SHA-256 digests). Hardware: dual Intel Xeon
Gold 6130 (32 physical cores, 64 threads, AVX-512F/BW/DQ/VL, no VNNI), 377 GiB
RAM, one NVIDIA GeForce GTX 1070 8 GiB (SM 6.1, CUDA 12.0.140, driver 580.178.04).

## Findings and resolutions

| ID | Severity | Finding | Resolution | Verification |
|---|---|---|---|---|
| E01 | High | `KernelRegistry::select`, `find_by_id`, and `ModelRunnerRegistry::resolve_*` returned raw borrowed pointers (`const guild_kernel_op_desc_v1_t*`, `const IModelRunner*`) before the caller acquired a package lease. Concurrent `unregister_package` could erase the entry or unload the DSO in that gap. | Replaced raw borrowed pointers with reference-counted `KernelBinding` (`std::shared_ptr<const guild_kernel_op_desc_v1_t>` aliasing `StoredOp` + `library_keepalive`) and `std::shared_ptr<const IModelRunner>`. `active_package_leases(package_id)` counts both explicit `SessionKernelLease`/`SessionRunnerLease` holds and outstanding `StoredOp`/`IModelRunner` shared pointers (`use_count() - 1`) under the same lock. | `modular_abi_test` (12-thread adversarial selection/replacement under ASan+UBSan and TSan). |
| E02 | High | Cross-registry plugin installation and removal updated `ModelRunnerRegistry` and `KernelRegistry` under separate mutexes, allowing readers to observe half-published or half-unloaded hybrid packages. | Added `abi::provider_lifecycle_mutex()` (`include/guild/abi/lifecycle.hpp`) with a strict lock order: `GKernelPackageManager::mutex_` -> `abi::provider_lifecycle_mutex()` -> individual registry `mutex_`. | `modular_abi_test` transactional rollback and 12-thread concurrent replacement tests. |
| E03 | High | `AbiModelRunnerAdapter::validate_and_describe` mutated shared `RunnerTensorMap` strings (`mutable RunnerTensorMap tmap_`) during model load while other threads could read `tensor_map()`. | Removed mutation of registry-shared `tmap_` strings in `AbiModelRunnerAdapter`; `import_runner_model` validates canonical tensor roles without mutating shared adapter state. | `modular_abi_test` under TSan (`-fsanitize=thread`). |
| E04 | High | `GKernelPackageManager::install_package` deleted `<root>/packages/<id>/<version>` (`fs::remove_all(final_dir)`) before moving staged files into place and allowed overwriting an existing `package_id@version` with different content. | Enforced same-version immutability (`allow_same_version_replacement = false` by default): identical content is an idempotent no-op or re-enable; different content for an existing `package_id@version` (active or retained in `version_dirs`) is rejected with `GUILD_STATUS_ERR_DUPLICATE_REGISTRATION`. New versions publish into `<root>/packages/<id>/<new_version>` before unloading the previous version. | `modular_abi_test` same-version immutability and subprocess crash tests. |
| E05 | High | `save_registry_unlocked` and `PackageSecurityPolicy::save_to_file` wrote `.tmp` files via `std::ofstream` without `fsync` or directory sync, and `remove_package` deleted on-disk package files before committing `registry.json`. | Implemented `write_file_durable`, `sync_directory_durable`, and `atomic_write_json_file` (`open` + `write` + `fsync` + `fchmod` + `close` + `rename` + parent directory `fsync`). `remove_package` commits `registry.json` before deleting `<root>/packages/<id>`, and `init()` cleans up leftover `staging/`, `.tmp`, and unreferenced package directories. | `modular_abi_test` 6-boundary fault injection and `fork()` + `_Exit(99)` crash recovery tests. |
| E06 | High | `GuildSession` stored only a raw `GuildModel*`. Destroying `GuildModel` while a `GuildSession` handle remained alive left dangling pointers to `GuildModel::Impl` and `main_stream`. | `GuildModel` now shares `std::shared_ptr<Impl> impl_`, `std::shared_ptr<Tokenizer>`, and `std::shared_ptr<std::atomic<bool>> ready_` with `GuildSession::Impl`. `GuildModel::~GuildModel()` marks `ready_ = false`; `GuildModel::Impl::~Impl()` destroys `prefill`, `batched_prefill`, `ver` (CUDA graphs), `mtp`, and `pool` (CPU threads), synchronizes `main_stream`, and only then releases provider bindings and package leases. | `ornith_gkernel_plugin_test` Phase D orphaned-session test and 8-session concurrent inference test. |
| E07 | Medium | Global `active_sessions()` counters in `KernelRegistry` and `ModelRunnerRegistry` blocked disabling or removing an unused package whenever any unrelated session was active. | `unregister_package`, `unregister_runner`, and `unload_package_unlocked` now gate on `active_package_leases(package_id) > 0` (including live `KernelBinding` / `IModelRunner` references) rather than global `active_sessions()`. | `modular_abi_test` unrelated-package lease isolation test. |
| E08 | Medium | `stage_gkernel_source` only rejected undeclared `.so`/`.dll`/`.dylib` files, did not reject trailing bytes in `GKPK` archives or truncated `.tar` blocks/padding, and `validate_gkernel_package` did not check `validation_fixtures` SHA-256 digests on disk. | `stage_gkernel_source` now rejects any file not declared in `artifacts` or `validation_fixtures`, rejects trailing `GKPK` bytes and truncated `.tar` headers/padding, and `validate_gkernel_package` verifies on-disk `validation_fixtures` SHA-256 digests. | `modular_abi_test` Section 5b archive security tests. |
| E09 | Medium | `session_own_qsa_staging` checked `std::getenv("GUILD_KV_SHARE_STAGING") != nullptr` in a `static const bool`, treating `GUILD_KV_SHARE_STAGING=0` as shared staging and ignoring VRAM pressure or multi-session staging budgets. | Implemented dynamic `session_own_qsa_staging` and `session_set_kv_share_staging` parsing `0`/`1`/`auto`, `GUILD_KV_STAGING_BUDGET_MIB`, `GUILD_MAX_CONCURRENT_SESSIONS`, and automatic VRAM headroom fallback in `GuildModel::load`. | `kv_host_only_test` and `bench/results/phase2e-multisession/staging-*.json`. |

## Sanitizer and concurrency verification

- **AddressSanitizer + UndefinedBehaviorSanitizer (`-fsanitize=address,undefined -fno-omit-frame-pointer`)**:
  `modular_abi_test` passed (`15.62 s`, 0 sanitizer findings) covering ABI v1 negotiation, Ed25519 verification, malformed archive staging, 6-boundary fault injection, subprocess crash recovery, and 12-thread adversarial concurrent selection/replacement.
- **ThreadSanitizer (`-fsanitize=thread -fno-omit-frame-pointer`, `setarch x86_64 -R`)**:
  `modular_abi_test` passed (`17.98 s`, 0 data races) across 8 concurrent reader/executor threads, 2 inspector threads, and 2 package install/rollback modifier threads.
- **Real-model CUDA concurrency (`ornith_gkernel_plugin_test` and `ornith_prefill_bench --sessions 8 --concurrent-pkg-ops`)**:
  Passed on GTX 1070 with 8 concurrent `GuildSession` workers and continuous background package list/inspect/disable/remove attempts (`35,304,054` busy-unload rejections observed in `ms-all-s8-p512.json` with 100% deterministic token parity).

## Trust boundary and explicit non-claims

- Ed25519 signatures and SHA-256 artifact digests authenticate publisher identity and file integrity before `dlopen`; they do not sandbox native plugin code once loaded into the process.
- Local package store directories (`<data_dir>/kernels`, `packages/`, `staging/`) and `trust_store.json` / `registry.json` are created with `0700` / `0600` permissions (`0500` for staged shared libraries, `0400` for read-only metadata/fixtures on POSIX).
- Process-global native embedding (`set_native_embed`), expert pack layout (`expert_layout()`), and RoPE configuration remain shared per process; concurrent `GuildSession` instances are validated sharing one loaded `GuildModel`, not simultaneous different-model instances in one process.
- This machine has one GTX 1070 (`gpu_device_count = 1`); multi-GPU execution across multiple physical devices was not claimed from this single-GPU host.
