# Phase 6.5 General Optimization Benchmark Artifacts

This directory contains the raw CSVs, `.startup.json` phase breakdowns, `.command.json` provenance metadata, frozen `.prompt.ids` files, counterbalanced 3-run A/B measurements, `manifest.json`, and generated SVG plots (`graphs/`) for Phase 6.5.

See [`docs/performance/PHASE65_GENERAL_OPTIMIZATION.md`](../../../docs/performance/PHASE65_GENERAL_OPTIMIZATION.md) and [`docs/performance/PHASE65_INFERENCE_RESEARCH.md`](../../../docs/performance/PHASE65_INFERENCE_RESEARCH.md) for the full research review, candidate ranking matrix, methodology, accepted and rejected prototypes, and summary tables.

## Contents

- `baseline/`: Phase 5.6 baseline measurements (`ornith-spec0`, `qwen-spec1`, `qwen-spec0`).
- `phase6/`: Phase 6 measurements and `llama.cpp` reference runs (`llama-pinned`, `llama-newer`).
- `optimized/`: Phase 6.5 measurements (`ornith-portable`, `ornith-gexec`, `qwen-portable`, `qwen-gexec`, `qwen-gexec-c64k`, `qwen-gexec-c128k`, KV precision sweeps `ornith-kv-*` and `qwen-kv-*`, and multi-session scaling `ornith-sessions-s*`).
- `ab-counterbalanced/`: 3-run full-warmup counterbalanced A/B measurements (`baseline-*` vs `phase65-*`) with bitwise-verified `.ids` and `.f32` logit dumps.
- `manifest.json`: Release benchmark manifest with `64` validated measurement groups (`0` exclusions) and full-file SHA-256 weight digests.
- `graphs/`: Validated `measurements.json` and SVG context-scaling, relative-decode, release-history, and `Guild / llama.cpp` speedup plots generated by `python3 tools/release_benchmarks.py bench/results/phase65-general-optimization/manifest.json --output bench/results/phase65-general-optimization/graphs`.
