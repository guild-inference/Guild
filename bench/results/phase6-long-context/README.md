# Phase 6 Long-Context & Reference Benchmark Artifacts

This directory contains the raw CSVs, `.startup.json` phase breakdowns, `.command.json` provenance metadata, frozen `.prompt.ids` files, `manifest.json`, and generated SVG plots (`graphs/`) for Phase 6.

See [`docs/performance/PHASE6_LONG_CONTEXT_OPTIMIZATION.md`](../../../docs/performance/PHASE6_LONG_CONTEXT_OPTIMIZATION.md) for the full analysis, methodology, and summary tables.

## Contents

- `baseline/`: Phase 5.6 baseline measurements (`ornith-spec0`, `qwen-spec1`, `qwen-spec0`).
- `optimized/`: Phase 6 measurements (`ornith-portable`, `ornith-gexec`, `qwen-portable`, `qwen-gexec`, `qwen-gexec-c64k`, `qwen-gexec-c128k`, `llama-pinned`, `llama-newer`, and KV format sweeps `ornith-kv-*`, `qwen-kv-*`).
- `manifest.json`: Release benchmark manifest with `38` validated measurement groups (`0` exclusions).
- `graphs/`: Validated `measurements.json` and SVG context-scaling, relative-decode, release-history, and `Guild / llama.cpp` speedup plots generated by `python3 tools/release_benchmarks.py bench/results/phase6-long-context/manifest.json --output bench/results/phase6-long-context/graphs`.
