# Qwen3.8-Flash-Next on this PC: 4-bit weights, FP16 KV

These measurements precede the decode regression fixes. Current matched old/new
results and the fixes are in [the regression report](qwen-runtime-regression-2026-10-14.md).

Measured on 2026-10-14 on Ubuntu: two Xeon Gold 6130 CPUs (32 physical cores, 64 threads),
376 GiB reported system RAM, and one GTX 1070 with 8192 MiB VRAM. NVIDIA driver 580.173.02;
the existing CUDA 12, sm_61 build of `build-cuda12/guild-generate` was used.

## Configuration

- Model: installed Unsloth UD-IQ4_XS, a mixed 4-bit quantization.
- Context capacity: 262144 tokens, with FP16 KV in pinned system RAM (`--kv-host-only`).
- Speculative decoding: `--spec 4` with `--mtp /mnt/models-ssd/Strata-data/mtp/rt`.
- Routed experts: all 24576 experts resident in RAM; 55.43 GiB copied and pinned at startup.
- GPU expert cache: zero slots; the GPU runs dense operations and the MTP draft.
- Prompt chunk: 512 tokens.
- Sampling: greedy, thinking disabled, no reused prompt tokens.
- Config: `guild-qwen-256k-fp16.json`; launcher: `run-qwen-256k-fp16.sh`.

The engine confirmed an 865 MiB draft layer and a 212.9 MiB draft head. Its log confirmed
captured one-, two-, three-, and four-token verification windows. The planner estimates
6 GiB for the main model's full-capacity FP16 KV cache; this is a planning estimate, not
a standalone allocation measurement.

## Measured results

Single warm-server runs. Long inputs repeat this repository's README, rendered through
the model's chat template and counted with its tokenizer. Rates come from the engine's
prompt/decode clocks; time to first token is measured at the streaming HTTP client.

| Prompt tokens | Generated tokens | Prompt processing | Time to first token | Generation |
| ---: | ---: | ---: | ---: | ---: |
| 1023 | 128 | 73.7 tok/s | 13.99 s | 17.6 tok/s |
| 8186 | 128 | 63.2 tok/s | 129.59 s | 15.3 tok/s |
| 32759 | 10 | 59.6 tok/s | 550.19 s | 17.6 tok/s |

The last row is a recall test, with a code word inserted halfway through the input. The
model correctly returned `cobalt-harbor-731`. Its ten-token answer is too short to treat
as a steady-state decode benchmark.

For comparison, MTP-disabled runs on the same 1023- and 8186-token prompts generated at
15.0 and 14.7 tok/s respectively. These are single-run comparisons, not statistical averages.

After the MTP-enabled tests, `nvidia-smi` reported 7677 MiB VRAM used. `free -h` reported
77 GiB system RAM used, 298 GiB available, and zero swap used. System RAM figures include
the PC's other services; process RSS also includes file mappings and is not equivalent
to additional physical RAM consumed by the model.

**The configured and loaded capacity is 262144 tokens. The longest tested prompt is
32759 tokens. A filled 262144-token prompt was not benchmarked.** Prompt, template, and
requested output must all fit within the context; the Python server also reserves eight tokens.

## Run it

The server was left running on `http://127.0.0.1:4782/` after successful tests.
To start it again after stopping that instance:

```bash
sh /home/ubuntu/Guild/run-qwen-256k-fp16.sh
```

Open the web chat at `http://127.0.0.1:4782/`, or configure an OpenAI-compatible client:

- Base URL: `http://127.0.0.1:4782/v1`
- Model: `qwen3.8-flash-next-unsloth-ud-iq4_xs`
- API key: none required locally; use `local` if the client requires a nonempty value.

Allow a minute or two for model loading. A 32K prompt took about nine minutes to read on
this GPU, so long prompts need correspondingly long client timeouts. Ctrl+C stops a
foreground launcher. The background server started for this benchmark can be stopped
with `kill -TERM 3033402` while that PID still identifies this instance.

## Reproduce the benchmarks

With the server running, from `/home/ubuntu/Guild`:

```bash
.venv/bin/python scratch/qwen_kv_benchmark.py --targets 1024,8192 --max-new 128 --out scratch/qwen-kv-fp16-mtp-repeat.json
.venv/bin/python scratch/qwen_kv_benchmark.py --targets 32768 --max-new 64 --needle --out scratch/qwen-kv-fp16-mtp-32k-repeat.json
```

Recorded raw results:

- `scratch/qwen-kv-fp16-short-benchmark.json` (MTP disabled).
- `scratch/qwen-kv-fp16-mtp-benchmark.json` (MTP enabled).
- `scratch/qwen-kv-fp16-mtp-32k-recall.json` (long-context recall).
