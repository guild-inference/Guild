- {"severity": "major", "what": "F1, latent NaN risk. The zero-tail cache (ztail) for lent slots in the scratch region goes stale after the MTP drafter's draft_kv, which uses the whole region including the lent slots, in place. When the next request repeats the lent layout (lay_out's early return for lt == region_T && zc == zc_mode), ztail is kept. A pinned-arena DMA of a blob the same size as the slot's ztail then skips its 256-B memset, and MMQ's down over-read reads draft_kv's fp32 leftovers. A scale that decodes as NaN or Inf (about 1/32 per low half-word) gives NaN * 0 = NaN in that expert's output. Not reachable with UD-IQ4_XS, because layer 0's blob (2,329,600 B) differs from layers 46-47's (3,148,800 B), so every slot's first pinned DMA memsets. It is reachable on a pack whose first and last layers' blobs are the same size. That also needs pinned DMAs (GUILD_PIN_EXPERTS=1, a PCIe-offload plan, or the automatic page-locking on a one-NUMA-node PC with a RAM budget <= 24 GiB), the MTP drafter on Pascal, and two consecutive single-chunk prompts of the same length (always true for benchmarks with --warmup and GUILD_NO_KV_CACHE).", "where": "src/prefill/prefill.cpp: lay_out's early return (line ~2774, 'laid out for this T already'), stage_copy's skip (line ~3083, 'zt == bytes || zt == kZcZero'), draft_kv's whole-region carve (line ~1713-1745).", "fix": "On that early return, set m.ztail[i] = 0 for i in [m.ring - m.ring_lent, m.ring).
